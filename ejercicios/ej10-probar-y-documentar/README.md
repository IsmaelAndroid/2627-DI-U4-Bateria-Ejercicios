# Ej10 · Probar y documentar 🟣

**Apartados 12 y 13 · Pruebas y documentación** · ⏱️ 25 min

> 🎯 Un componente se entrega **probado** y **documentado**. Aquí las pruebas son `require` (si falla, el programa se para con un error) y la documentación es un comentario **KDoc** (`/** ... */`), que es lo que ve quien usa la función en el autocompletado.

## Pasos

Completa [`Iniciales.kt`](Iniciales.kt) y ejecútalo:

```bash
./ejecutar.sh ejercicios/ej10-probar-y-documentar/Iniciales.kt
```

**PASO 3.** En Android Studio, escribe `iniciales(` en otro sitio y pon el ratón encima: verás tu KDoc.
