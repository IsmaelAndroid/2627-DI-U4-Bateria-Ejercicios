# Ej03 · Propiedades con valor por defecto 🟣

**Apartado 4 · Propiedades y atributos** · ⏱️ 20 min

> 🎯 Las propiedades de un componente son sus **parámetros**, y el **valor por defecto** del parámetro es el valor «de fábrica»: si no lo indicas, se usa ese.

## Pasos

Completa [`Etiqueta.kt`](Etiqueta.kt) y ejecútalo:

```bash
./ejecutar.sh ejercicios/ej03-valores-por-defecto/Etiqueta.kt
```

## ✅ Comprueba

```text
[Hola | negro | 14 sp]
[Aviso | rojo | 14 sp]
[Título | negro | 22 sp]
```
