# Ej06 · Un componente sin estado 🟣

**Apartado 6.2 · El componente** · ⏱️ 20 min

> 🎯 Un componente **sin estado propio** solo dibuja lo que le pasan: no guarda nada. Por eso sirve en cualquier pantalla. Aquí el «dibujo» es un texto.

## Pasos

Completa [`Badge.kt`](Badge.kt) y ejecútalo:

```bash
./ejecutar.sh ejercicios/ej06-sin-estado/Badge.kt
```

## ✅ Comprueba

```text
● Completado (verde)
● Caducado (rojo)
Revisa (ámbar)
```
