# Ej04 · Argumentos con nombre 🟣

**Apartado 4 · Propiedades y atributos** · ⏱️ 15 min

> 🎯 Con **argumentos con nombre** (`formal = true`) se puede cambiar solo el parámetro que interesa, en cualquier orden, sin escribir los demás.

## Pasos

Completa [`Saludo.kt`](Saludo.kt) y ejecútalo:

```bash
./ejecutar.sh ejercicios/ej04-argumentos-con-nombre/Saludo.kt
```

## ✅ Comprueba

```text
Hola, invitado
Hola, Ana
Buenos días, invitado
Buenos días, Sr. Ruiz
```
