# Ej07 · Un componente que avisa con un evento 🟣

**Apartado 6.3 · Un componente con evento: SelectorMes** · ⏱️ 20 min

> 🎯 Un componente avisa de lo que pasa con un **evento**: un parámetro lambda. El selector de meses no sabe para qué se usa; solo avisa del **número** del mes elegido.

## Pasos

Completa [`Selector.kt`](Selector.kt) y ejecútalo:

```bash
./ejecutar.sh ejercicios/ej07-evento/Selector.kt
```

## ✅ Comprueba

```text
Abono recargado para el mes 3
Abono recargado para el mes 12
```

> «Brumario» no es un mes del selector: no se avisa.
